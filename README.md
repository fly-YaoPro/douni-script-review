# 豆尼审稿 · 团队版

给各位审核同事使用的本地审稿 Skill：完整 Brief、会议全文、历史学习样本及豆包内置 Skills 参考随包提供。

- 每次审稿先核验 GitHub `main`；有更新自动备份、更新并重新读取规则。
- 读取文档和写局部评论均用使用者自己的飞书账号，维护者也一样。
- 区分大纲、常规课程教学、3W 课程教学、工作任务和独立端；先审内容再复核意见。
- 无需 Linkly、豆尼服务端或共享个人 Token。

本仓库已公开，可安装到自己 AI 客户端的 `skills/douni-script-review` 目录。具体步骤见 [安装和更新](references/team-setup.md)。装好后直接发飞书稿件链接并说“审稿”即可；首次请核对助手报出的飞书登录姓名。

2026-09-10 核对当前团队版。仓库包含业务参考资料，资料和样本保留原有归属；公开可见不代表获得二次商业使用授权。飞书链接仍按使用者本人的文档权限访问，不附带维护者登录态。仓库最新版不等于源资料刚更新，来源同步时间保留在各文件和 manifest 中。
