# 从真实审稿中学习

适用：用户要求学习或消化本周稿件、评论、改稿，提升审稿能力。这是知识维护，不是重新审稿或重新发评论；不改飞书正文、状态、评论和权限。学习后的能力是资料与判断流程改进，不能声称已经重训模型或证明总体准确率提高。

## 发现与覆盖

沿用本人身份和版本核验规则。周范围按用户时区；执行入口优先本次链接，其次已有且确认有效的个人业务配置或 `DOUNI_WEEKLY_EXECUTION_DOC`。共享 Skill 不写死维护者的周文档。当前周尚未结束时，只覆盖已出现日期，不把后续日期记为遗漏。

读取各机构日快照的待审核、推进脚本/推进细化、待修改、待开拍列，按文档稳定 ID 去重，保留每次出现的日期、机构、专项和阶段。大纲、脚本、3W、常规、工作任务和独立端分别标识；同名不同期、不同链接不因名字相同而合并。引用链接可能是参考资料，不自动算一篇稿件。

先读取已解决及未解决评论，完成分页；有明确嵌入表格时，品牌反馈单元格也是审核来源，不能因为文档评论为空就当“无审核”。全文与表格原始顺序须保留，不能只取被评论句子。图片、视频、演示产物没有实际打开就标为未核验。

工作量大时优先深读：本周有新意见/修改、从修改转开拍、同人不同期、主讲能力不同、3W与常规形成对照的稿件；包含可保留的好段落、无效改法和局部改好但整体未改齐的样本。明确报告发现数、评论可读数、全文深读数、历史版本对照数及剩余项，四者不能混称完成。

## 来源与证据

- 记录评论 ID、当前署名和账号、时间、引用原文、回复、锚点、当前 revision。检查本机审稿运行账本中的评论 ID/单元格写入记录及用户明确确认的反馈。AI 使用本人身份发布仍是 AI 输出；不能只过滤机器人 ID，也不能把其他账号自动视为已验证真人。
- 来源分为 `user_confirmed`、`known_ai`、`platform_attributed_unverified`、`unknown`。后两者可作带保留的观察样本，不标真人金标准；`known_ai` 仅用于错误复盘，不能自我认证为正确。
- 原发起人的意见与创作者回复、解决者分开；回复“改好了”不是验收。按时间读取评论之前最近可用的完整历史版本，再读取当前完整版本。历史接口分页；查不到就降级为“原引用—当前文本”，不伪造改前全文。不要把 relation 的 objVersion 直接认定为评论创建时的正文版本。
- 版本不同也可能是别处改动。逐条检查本项语义变化与关联段落，分别记录 `changed_addresses_issue`、`partially_addressed`、`unchanged`、`cannot_verify`。这只是本轮文本判断，不代替客户批准。
- 评论已解决不等于意见正确；正文锚点被删不等于评论被删。用户明确删除/否定的意见记录为负例，不能自动重新补回。当前接口不返回的评论不凭空恢复。

## 提炼方式

先完整还原这篇承诺，再问“这条意见改善了什么，哪部分已经够好，最小改动是什么”。提炼判断关系而非指定句式、字数或技能数量。特别比较：

1. 教程是在解释关键输入与取舍，还是只念操作和结果？辅助能力是否挤掉本期重点？
2. 产物介绍是在告诉观众如何使用、为什么好，还是只报页数/模块数和“效果很好”？有价值的现成产物是否被长铺垫压住？
3. 多个能力是否有真实交接，上一段结果如何进入下一段？双端场景是否服务这个任务，而非每段都加同款广告？
4. 复用的是内容方法还是连开头、过渡、结尾都复制？只有实际读到相似稿件才判断同质化，不凭“像AI”定罪。
5. 改了主体后，标题承诺、封面文案、结尾和大纲是否仍残留旧内容？不要把留档旧大纲直接当现行口播。

每条精选案例保留：原文/版本、实际意见、当前文本、来源等级、修改状态、可复用判断、适用条件、不能推广的反例。只学习文字表达改善时，不能顺带把产物功能、活动权益、平台禁词或审核者拍摄偏好认证成事实。

## 保存与生效

原始全文、评论和个人身份账本存 `.local/learning/<批次>/`，索引用 `.local/learning/index.json`，不提交共享仓库。经过本轮主编判断的少量匿名化内容原则可进入 `references/`；发布前核对文件差异、敏感信息、引用与原文，按维护者既有发布授权操作，不自动上传原始整库。

未获发布授权时只保存在 `.local/learning/`，明确是本机增量，不称同事已更新。共享更新不得覆盖个人原始证据；新增全局规则需要当前业务依据，不以样本频率代替授权或事实核验。

至少做一轮反例检验：同样问题换成3W会不会不适用；大纲是否被误按脚本要求；单次体验是否被当承诺；有画面说明是否又要求口播重复；删掉的意见是否重生；署名本人AI是否混成真人。自动测试只能检验路由/证据结构，不能证明内容能力提升。
