# **一、项目概况**

### **1.1 业务背景**

- 以 "**30天教会Agent从入门到精通**" 为核心主题，与达人建立长期合作，打造系列化教程视频 ，执行节奏为**每账号每周产出 2 期，总发布可达 5\~10 期**，让观众循序渐进地了解豆包Agent不同玩法，能对工作、学习分别起到什么帮助。
- **推广周期：8月20日之后长期做，确认合作后需迅速推进，不可延期太久**



### **1.2达人画像**

- **核心人群：抖音AI科普博主**
- 不要AI资讯博主
- 有无真人出镜都可以
- 合作价格、数据、粉丝段需满足过往要求

# 三、创作注意事项

### 1.1 KOC在两个方向任选其一

1. “如何从0到1使用豆包工作？”这种基础入门教学
2. 双端互通、云电脑、SeedAudio 等新功能介绍

⚠️这两类内容都要加上双端互通、云电脑相关内容，需重点突出该核心优势<cite doc-id="KM5nwJcLwieI1TkU6lncPkDtnEh" file-type="wiki" title="双端互通都能讲什么？" type="doc"></cite>



### 1.2 稿件及视频注意事项：

<callout emoji="👉">
核心心智就一句话：豆包有 **Agent** 了，能帮你**办公**了。带一下：下载PC送30天限免的，不限新老用户信息。
所有有内容输出的场景---写文档、做表格、出 PPT、整理消息、数据分析等场景，都可以引导用户让豆包 Agent 直接试试。
### **禁止豆包UI二创**
</callout>

**具体要求：**

1. 标题、封面、内容，合适的地方都要特别强调豆包有 agent
2. 需要在脚本中插入手机电脑多端互通、手机云电脑这两大优势，具体如下：

https://www.doubao.com/thread/xCSGzqWnkRHLcYOgV

不能只是一句话带过，需要通过具体的场景和细节让用户意识到，它的方便、实用以及只有豆包可实现

1. 注意教程感，主要篇幅是讲解各种skill，并做演示，以此让大家知道豆包的agent玩法
2. 时长1分30s左右的定制视频，口语化表达，不要有广告味
3. 拍摄时，采用真人口播+录屏的形式
4. 脚本里不提「工作任务模式」，以「豆包工作」来指代
5. 标题里尽量带 "Agent" 或 "能办公" 的信号，让用户一眼知道这是Agent能力
6. 正文别只讲功能，要讲 "它帮你办完了什么"，突出从 "辅助" 到 "代办" 的变化
7. 结尾加一句行动引导，比如 "有内容输出的地方都可以让 Agent 跑一遍"
8. 口播及字幕注意提到豆包
9. 提及豆包工作概念和具体技能的时候，需要用自己的语言和用家的视角，说清楚：这是什么、我是怎么用/理解的



### 1.3 稿件结构示例：（主要针对“如何从0到1使用豆包工作？”这种基础入门教学）

#### 1️⃣稿件逻辑分类：（达人大纲可参考其中一个）

- 代入自身场景，去介绍哪个skill适合解决什么问题（举例2-3个），边讲解边演示

# 四、发布注意事项

1. 封面、标题要有豆包agent的字样（都加上，不是可选项）
2. 维护评论区，需要与评论区高频互动，解答使用问题，引导用户互动
3. 需在评论区置顶使⽤指令，如若限流可以考虑在发布后12h后置顶评论/使用图片截图的方式贴出
4. 必带话题：#豆包agent #豆包工作任务



# 五、封面设计标准

#### **1️⃣设计标准：**

1. 有大大的「豆包Agent」字样，确保产品信息的有效露出

3. 给足信息，以具有吸引力的文字点明视频主旨（例如，写论文必装的3个skill）
4. 确保画面美观度
