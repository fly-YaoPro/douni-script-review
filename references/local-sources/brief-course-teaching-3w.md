# **一、项目概况**

### **1.1 业务背景**

- 豆包工作任务模式，支持双端互通，达人结合自己实际用例，需重点突出该核心优势，规避内容质量过于空泛的讲解。执行节奏为**每账号每周产出 2 期，总发布可达 5\~10 期**，让观众循序渐进地了解豆包Agent能对工作/学习起到什么帮助。
- **推广周期：8月20日之后长期做，确认合作后需迅速推进，不可延期太久**



### **1.2达人画像**

- **核心人群：抖音AI科普博主**
- 不要AI资讯博主
- 有无真人出镜都可以



### **1.3达人权益沟通**

- 合作排竞：合作期间及合作结束后7天内(前7后7)，达人不得接单同赛道竞品
- 内容分发：合作内容需分发至抖音主站(必选)，优质内容可同步至b站
- 内容授权：内容需授权信息流投放及二剪使用，授权时长至少要求1年
- 保留时长：内容保留时长要求1年

# 四、其他要求

### **4.1稿件撰写要求：**

1. 标题、封面、内容，合适的地方都要特别强调豆包有 agent
2. 注意教程感，让大家知道豆包agent如何正确使用
3. 时长1分30s左右的定制视频，口语化表达，不要有广告味
4. 开头要告诉大家这个视频教什么内容，把重点单独预告highlight下
5. 脚本里不提「工作任务模式」，以「豆包工作」来指代
6. 定制、真实、深度体验内容，不接受中插、⼴告感重的AI⽂案、营销内容 
7. 使⽤场景具体&真实，不要宽泛的提问，不要⽆重点的截图堆叠
8. 正文别只讲功能，要讲 "它帮你办完了什么"，突出从 "辅助" 到 "代办" 的变化
9. 结尾加一句行动引导，比如 "有内容输出的地方都可以让 Agent 跑一遍"
10. 结尾要带上活动政策：PC端豆包送30天会员，不限新老

### **4.2拍摄要求：**

1. 拍摄时，采用真人口播+录屏的形式
2. 口播及字幕注意提到豆包
3. 视频内容中豆包露出不晚于20秒，截图避免中插、快闪式展示，保障内容停留时间和清晰度

### **4.3发布要求：** 

1. 封面、标题要有豆包agent的字样（都加上，不是可选项）
2. 标题里尽量带 "Agent" 或 "能办公" 的信号，让用户一眼知道这是Agent能力
3. 维护评论区，需要与评论区高频互动，解答使用问题，引导用户互动
4. 需在评论区置顶使⽤指令，如若限流可以考虑在发布后12h后置顶评论/使用图片截图的方式贴出
5. 必带话题：#豆包agent #豆包工作



关注重点：**真实分享  热点传播 用户互动（重点：注重互动专业性内容的产出，真实分享）**



# 五、封面设计标准

#### **1️⃣设计标准：**

1. 有大大的「豆包Agent」字样，确保产品信息的有效露出
2. 给足信息，以具有吸引力的文字点明视频主旨（例如，写论文必装的3个skill）
3. 确保画面美观度
