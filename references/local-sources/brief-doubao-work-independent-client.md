# 二、同样是 Agent，豆包工作有这些不一样（tob）



对企业用户来说，豆包工作真正的变化不是多了一个AI办公工具，而是让Agent开始进入团队的工作现场——

1. **飞书原生，成果直接留在组织里：**用飞书账号登录，豆包交付的文档、表格、任务直接落在飞书生态里，可以设分享权限、直接@同事协同编辑，工作成果和经验留在团队中继续编辑、分享和复用，不会散落在个人对话框里。
2. **有最好的企业上下文，不用反复喂prompt：**飞书把文档、群聊、会议纪要、多维表格、审批、组织关系都放在同一套体系里，豆包工作能直接读取理解——知道这个项目谁负责、之前在哪个群讨论过、哪份文档是最新版、老板关心什么。普通Agent只能根据你当下输入判断意图，豆包工作能理解组织里的关系和决策来龙去脉。
3. **能推进工作，不只是生成内容：**基于会议纪要自动给负责人创建任务并跟进状态；读取群聊还原项目进展和风险点；查询审批状态并拉群跟进；把多维表格变成实时数据看板；还能和企业内部系统打通，查询业务状态、更新数据。它交付的不是一次总结，而是把信息整理、应用搭建和团队沟通串成一套可以继续推进的工作。
4. **企业级安全，管得住看得见：**严格继承飞书原有权限，员工看不到的信息Agent也看不到；个人与企业数据完全隔离；管理员可灵活管控用户权限和使用额度；全链路安全防护，从设备接入、权限管控、数据加密到操作审计；还通过了中国信通院"互联网智能体治理-办公智能体能力"及"云端OpenClaw基准测试能力"双项认证。



总结：豆包工作，可以完全融入人在飞书里的工作，不只是提升个人效率，而是提升整个组织的效率。
