# 来源发现

单篇及直接给出的一组链接不执行全业务来源发现。批量任务的当前周执行文档集优先使用用户本次指定的链接，其次读取环境变量 `DOUNI_WEEKLY_EXECUTION_DOC`；均未提供时询问执行文档入口，不默认使用维护者的文档。可选机构 Base 由 `DOUNI_EXECUTION_BASE` 指定，不在共享 Skill 中写死。用户个人配置和执行记录置于 `.local/` 并排除 Git 跟踪。

## 动态发现

1. 读取总执行文档“二、机构执行表格”。
2. 只接受标题日期与本周相交、且机构名可识别的文档。
3. 机构范围从用户指定的执行文档实时发现，不用历史名单限制范围。
4. 当周未提供的机构列为“来源缺失”，不能记为 0 个待审核。

## 候选规则

- 在机构文档中读取所有 `5.1 机构提报脚本` 区块。
- 定位第一张含“待审核、推进细化、待修改、待开拍”的表格，只取“待审核”列。
- 专项取该列中最近的标签；历史“科普/科普号/科普专项”统一为“课程教学”。
- 明确标记为“大纲”的文档不审核；“大纲脚本一块写”等明确包含脚本的材料保留。
- 平台优先从文档标题 `【抖音】/【小红书】` 识别，无法识别时再查机构执行表，不得猜。
