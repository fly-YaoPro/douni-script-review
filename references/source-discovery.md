# 来源发现

当前周执行文档集从环境变量 `DOUNI_WEEKLY_EXECUTION_DOC` 读取；未配置时使用当前登记的用增周执行文档集。

## 动态发现

1. 读取总执行文档“二、机构执行表格”。
2. 只接受标题日期与本周相交、且机构名可识别的文档。
3. 当前标准机构：闪光点、山恒、筑石、纽微特、志森、杭杭、萌兽、睿立、肆野、金铲子、诺信、映画。
4. 当周未提供的机构列为“来源缺失”，不能记为 0 个待审核。

## 候选规则

- 在机构文档中读取所有 `5.1 机构提报脚本` 区块。
- 定位第一张含“待审核、推进细化、待修改、待开拍”的表格，只取“待审核”列。
- 专项取该列中最近的标签；历史“科普/科普号/科普专项”统一为“课程教学”。
- 明确标记为“大纲”的文档不审核；“大纲脚本一块写”等明确包含脚本的材料保留。
- 平台优先从文档标题 `【抖音】/【小红书】` 识别，无法识别时再查机构执行表，不得猜。
