# 最小可用降级产物

缺少阻断输入时，不能只回复“请上传材料”。至少交付：

- 当前可确认的最小事实和可答结论
- 研究、初会、数据室信息获取、投资推进和回报 gate 与各自暂停槽位
- 最多五个分别覆盖主体/技术、收入回款、临床增量、单位经济和交易的问题
- 每个问题的升级/降级条件
- 等待材料期间可完成的公开核验与下一决策节点

规则：

- 只使用已知事实；
- 不填默认数字；
- mandate 缺失只暂停 mandate fit，交易输入缺失只暂停交易质量、投资推进或回报；
- 不要求信息收集型初会前已有审计财报、合同、cohort 或 Term Sheet；
- 标出恢复完整执行所需的最少输入。
