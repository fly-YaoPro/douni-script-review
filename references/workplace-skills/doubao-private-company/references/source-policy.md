# 一级投资项目评估 来源与证据规则

## 来源层级

| 优先级 | 来源 |
|---|---|
| 1 | 用户提供的 BP、Deck、CIM、Teaser、财务和访谈记录 |
| 2 | 工商、监管注册、知识产权、政府采购和发布机关材料 |
| 3 | 可购产品、渠道、客户/医院、用户、支付方、供应商与行业第三方验证 |
| 4 | 交易条款、资本结构、股权表和历史融资 |
| 5 | 管理层预测必须标为 management claim，不能等同外部事实 |

## 证据类型

| 类型 | 定义 | 正文措辞 |
|---|---|---|
| fact | 一手来源或用户确认事实 | 可直接陈述，并标来源与日期 |
| estimate | 外部预测、模型或派生计算 | “估计/测算/一致预期”，暴露输入 |
| inference | 多项事实支持的分析结论 | “指向/可能意味着”，给证伪条件 |
| assumption | 为继续分析采用的透明假设 | 明确写“假设”并可修改 |
| management_claim | 公司/管理层陈述 | 写“公司表示”，不得当独立事实 |
| data_gap | 缺失、过期、冲突或不可访问 | 说明影响与下一步 |

## 新鲜度

- 价格、估值、预期、事件状态：必须标 as_of。
- 定期报告：标报告期和发布日期。
- 用户材料：标文件名、版本或提供日期。
- 旧资料若仍使用，说明为何仍适用。

## 数字纪律

- 数字必须有期间、单位、币种和来源。
- 派生数字引用输入 claim，并记录 calculation。
- 不同会计口径、财年和币种不能静默混用。
- 无法核验时宁可省略或写 data gap，不从记忆补数。

## 工具降级

可调用私有数据源时优先使用用户授权数据；不可用时转公开一手来源；仍不可用时输出方法、数据需求和局限，不伪造完整结果。

## Search 与引用规则

1. 每个问题最多 3 轮搜索，先找一手来源，再补二手解释。
2. 数字主张必须在同一段落给出来源 URL；文末堆链接不算完成引用。
3. 搜不到一手证据时，不用二手文章拼出精确数字。
4. 只有低质量来源时，结论降为“待核验线索”，不得进入估值、排名、概率或行动建议。
5. 澄清题、边界题和负例不为满足“必须搜索”而扩写无关案例。

## 公开商业化证据阶梯

监管注册、市场可购、政府采购、渠道上架、客户/医院使用、用户采用和支付方覆盖，可按各自能力交叉验证“获准—可购—采购—部署—使用—支付”。每类证据只升级其直接支持的状态，不能跨级推出收入确认。

媒体融资报道、投资人宣传和公司自述只能形成待核验线索。公司自述即使包含收入数字，也不能单独升级付款、收入确认或复购；须由监管申报/审计财务、客户/医院/支付方核验或付款记录承担。
