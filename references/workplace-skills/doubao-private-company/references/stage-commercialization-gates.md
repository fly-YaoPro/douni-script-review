# 阶段与商业化门禁

- 阶段状态：私有、受理、过会、注册、发行、上市；不得把注册机械等同上市。
- 阶段事实与基金 Mandate 决定交易推进槽位；Hard Pass 后停止对应交易推演，但不停止仍可回答的商业、技术或估值方法分析。
- 首先核验当前可投资交易：是否仍有新股/老股额度、工具、估值、锁定期及投资者权利。注册生效不能推出募资到账、发行估值或Pre-IPO额度存在。
- “存在参与路径”必须由明确额度和工具证据支持；否则交易可行性为 unknown。若主体真实、无明确 Hard Pass 且存在高信息价值 kill questions，仍可建议证伪型初会；若只需确认融资真实性和工具，则先与融资方核实。
- 商业化分别记录监管注册、可购、政府采购、渠道、客户/医院部署、用户采用、支付方覆盖、付款、收入确认、复购和客户类型。各状态可交叉验证，但不得跨级替代。
- 媒体融资、媒体收入估计、公司自述、演示和曝光不能提升付款、收入确认或复购状态。
- 集成商中标不能自动归属项目公司收入；供应商合作不能证明其是付费客户；冻结点后材料不得使用。
- 单位经济阈值记录商业模式、阶段、ICP、ACV、销售模式、地区、期间和来源。
- Deeptech/AI 技术证据依次记录性能演示、独立验证、可制造或可部署、系统集成、客户采用、付费续约、单位经济和规模化资本需求，禁止跨级升级。
- 技术证据前先冻结目标产品 taxonomy：传感模态、刺激/解码、医疗/消费、硬件/软件及法人业务边界。相邻模态、相邻产品或关联法人商业化不得归属目标对象。
- 商业或技术的产业价值与目标公司通过合同、IP、数据和议价权可捕获的价值分别记录。
