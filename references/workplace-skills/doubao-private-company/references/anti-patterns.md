# 一级投资项目评估 反模式

| 反模式 | 问题 | 修复 |
|---|---|---|
| 角色口号替代方法 | “作为资深专家”不能定义任务 | 改成输入、步骤、来源与门禁 |
| 数据罗列 | 数字没有机制和判断 | 推到约束与证伪 |
| 单一故事 | 把唯一解释写成事实 | 列竞争性假设和区分证据 |
| 工具幻觉 | 假设 MCP/CLI 一定存在 | 先探测能力，提供降级路径 |
| 伪精确 | 缺输入仍给概率、收益或估值 | 输出计算所需输入和方法 |
| 来源漂移 | 把媒体、管理层或模型推断写成事实 | 使用 claim_type 与限制语 |
| 大包全读 | 一次加载所有 references | 按模式和步骤精确读取 |
| 固定载体 | 强制 HTML/DOCX/飞书影响分析逻辑 | 内容契约与呈现分离 |
| 隐藏副作用 | 未确认就写入、发送、交易或上报 | 明确权限并二次确认 |

## 本 Skill 特有风险

- 不把九章 IC Memo 直接塞进初筛 Skill。
- 不默认某一基金的收入、EBITDA、地区和规模标准。
- 不在缺少交易条款时硬算 IRR/MOIC。
- 不把交易门禁上移为公开研究或信息收集型初会门禁。
- 不因缺 mandate、审计财报、合同、cohort 或 Term Sheet 整体拒答。
- 不在估值对象与权益边界未冻结时给默认倍数。
- 不用“满足 N 项”机械计数替代信息价值判断。
- 不把技术演示直接升级为客户采用、收入或单位经济。
- 不把媒体融资、公司自述或产品可购直接升级为收入确认。
- 不用相邻模态、相邻产品或关联法人证明目标技术商业化。
- 不把数据室访问写成投资推进，也不用“收到 N 类材料”作为准入条件。
- 不把产业链总价值等同于目标公司可捕获价值。

## 评测暴露的反模式

- 正确路由后继续作答。
- 用搜索到的同名或同类对象替代用户输入。
- 为填满模板生成无来源数字。
- 文末堆链接，但正文数字不绑定来源。
- 在澄清题中滥用搜索和扩写无关案例。
- 只输出材料清单，不说明问题如何升级或降级判断。
- 初会问题重复追问同一信息增量，遗漏主体/技术、收入回款、临床增量、单位经济或交易中的类别。
