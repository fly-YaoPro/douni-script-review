# Ark 输出契约

先执行复杂度路由，再按对应槽位完整交付。开头先回答用户的自然问题，随后分别输出 `can_form_research_view`、`can_recommend_management_meeting`、`can_recommend_data_room_access`、`can_recommend_investment_progression`；回报另列 `can_compute_returns`。false gate 只暂停其 `blocked_slots`。

Direct/brief 最多列五个 kill questions，分别覆盖主体/技术、收入回款、临床增量、单位经济和交易，每个写明升级与降级条件。初会门槛是预期信息价值，不是会前材料完整度。数据室仅是初会后的条件式信息获取层。估值先对象与权益边界，再给关系式；技术路线先做 taxonomy，再给证据阶梯，并区分产业价值与公司可捕获价值。

临近输出上限时删除背景、方法说明和重复数字，不得删除直接结论、分层 gate、关键证据、暂停槽位、升级/降级条件和收尾。API状态为 incomplete 或 finish_reason=length 时不得交付。
