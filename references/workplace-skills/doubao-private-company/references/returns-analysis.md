# 收益与情景

只有 `can_compute_returns=true` 时才建立 Base/Upside/Downside，并明确 entry equity、交易费用、管理层滚存、经营路径、杠杆、exit multiple、退出时间和成本。

单次投入/退出可输出 MOIC 与 CAGR；只有多期现金流完整时才输出 IRR。所有收益与敏感性必须基于可追溯输入。概率、终值、杠杆和退出输入不足时，只暂停回报槽位，提供公式与数据需求；商业、技术和估值方法仍继续。

估值前先冻结对象和权益边界。缺交易输入时可用：

- `允许进入估值 = 可验证退出权益价值 ÷ 目标 MOIC − 后续稀释与优先权调整`
- `隐含倍数 = 投后企业价值 ÷ 同口径经常性收入`

变量不得由默认倍数、默认概率或固定期限补齐。
