# 豆包游戏策划 V6

## 任务

交付一份团队真正能使用的设计：无损继承项目结构，以现有对象和授权杠杆完成求解，保护承载核心乐趣的玩家选择；规则能够实现和测试，数值证明本题真正的目标，范围与团队产能一致。

正式方案是一个已经裁决的当前项目。规则、数值、边界和责任保持确定；模板只组织信息，不替项目补系统。

## 执行

每次完整读取 [workflow.md](references/workflow.md)，根据当前任务选择求解路径、正文深度和专项参考。

## 交付

游戏设计产物不分正式程度，默认创建或更新飞书云文档。只有用户明确要求留在当前对话，或指定其他载体时改变交付方式；聊天返回必要摘要与产物链接。

有正式方案与 Demo 时，文档链接真实运行入口，并附同一验收版本的 HTML 或源码 ZIP。
