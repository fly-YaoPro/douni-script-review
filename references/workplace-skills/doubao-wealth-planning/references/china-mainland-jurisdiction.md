# 中国大陆辖区模块

仅在 `jurisdiction_or_market=中国大陆` 时按需加载。本模块不替代税务、法律、保险或持牌投资意见。

## 首轮辖区冻结

确认：

- 常住省市与社保、公积金缴存地；
- 中国税务居民身份及是否存在跨境收入、账户或资产；
- 主要币种及外币负债；
- 收入口径是税前、税后，是否已扣个税、社保和公积金；
- 家庭成员、赡养和抚养责任；
- 自住房、投资性房产、按揭及公积金贷款；
- 基本养老、企业年金、职业年金、个人养老金的参与状态。

缺省市时，不输出当地社保、公积金、失业保险和购房政策数字。

## 家庭基线口径

分开记录：

1. 可立即使用现金；
2. 银行存款与存款保险覆盖口径；
3. 银行理财、公募基金、券商账户等非存款资产；
4. 住房公积金、个人养老金及其他用途受限资产；
5. 自住房和投资性房产；
6. 商业保险现金价值；
7. 按揭、消费贷、经营贷和其他负债；
8. 税前收入、税后到手、社保公积金个人缴费和单位缴费。

不得把公积金、个人养老金、保险现金价值或受限资产直接计入日常应急资金。

## 目标与风险

- 目标按基本生活、医疗保障、债务、教育、住房、养老和可选消费排序。
- 风险偏好与风险承载能力分开；房产集中、收入行业集中、单一币种和家庭责任会降低承载能力。
- 不因用户自称“高风险偏好”直接提高权益资产区间。
- 不推荐具体基金、理财、保险、信托或房产项目。

## 规则 Search

按适用年度和省市优先检索：

1. `gov.cn`、国家法律法规数据库；
2. `chinatax.gov.cn` 及主管税务机关；
3. `mohrss.gov.cn` 及当地人社部门；
4. 当地住房公积金管理中心；
5. `pbc.gov.cn`、`nfra.gov.cn`、`csrc.gov.cn`；
6. 国家社会保险公共服务平台及依法公开的地方政务平台。

商业媒体、银行营销页、自媒体和产品销售材料不能承担税率、社保、公积金、养老金、存款保险或监管边界等关键规则。

## 数据纪律

- 个税、专项附加扣除、社保、公积金、失业保险和个人养老金限额必须绑定适用年度与辖区官方来源。
- 不根据税前收入直接估算税后收入，除非用户授权并提供足够扣除信息。
- 不默认社保缴费基数、公积金比例、失业保险待遇、养老金替代率、房价涨幅或投资回报。
- 政策数据不完整时使用变量，并列出主管部门核验路径。

## 中国大陆压力情景

至少覆盖：

- 单收入或双收入中断；
- 医疗和照护支出上升；
- 房贷利率或月供变化；
- 房产流动性折价；
- 跨境资产或外币负债波动；
- 社保、公积金或养老金缴费中断。

情景参数来自用户、合同或官方规则；无依据时使用符号变量，不填默认值。

## 专业转介

以下事项只做问题清单和材料准备：

- 个税申报、股权激励、经营所得和跨境税务；
- 婚姻、继承、赠与、监护和遗嘱；
- 保险核保与具体产品；
- 具体证券、基金、理财和资产管理产品；
- 外汇额度、跨境资金流和境外投资合规。
