# 家庭预算、净资产、消费、目标与债务模式

这些是同一财富规划主工件下的按需模块，不拆成微 Skill。

## 输入与边界

- 预算：税后月收入、用户分类支出和逐项分配；不套用固定比例。
- 净资产：资产/负债余额、as-of、估值来源和流动性；交易流水不能替代余额，房产/车辆估值不能由模型补写。
- 消费：至少两个可比期间、分类覆盖率、一次性事项；阈值由用户提供，未提供时只列变化。
- 目标：金额、期限、当前资金、优先级；转账备注不能证明目标余额。
- 应急金：必要支出和用户选择的目标月数；任何常见月数只能作为待讨论情景，不是默认规则。
- 债务：余额、APR、最低还款、期限和提前还款规则；缺 APR 时不得给雪崩顺序或利息节省金额。
- 周期扣款：只列年化成本和人工复核项，不能推断未使用、替代品可行或已经取消。

## 工作流

1. 冻结家庭、as-of、辖区、币种和账户范围。
2. 先核对收入、支出、资产、负债和交易覆盖；unknown 保持在各自槽位。
3. 用确定性工具计算净资产、月结余、用户预算未分配额、目标覆盖、应急金差额和债务模式。
4. 目标冲突时显式展示同一月结余约束；不得让每个目标分别占用同一笔现金。
5. 消费变化、生活膨胀和周期扣款只产生待解释/待复核清单，不生成道德判断或自动取消动作。
6. 输出行动草案；转账、还款、开户和产品购买均需另行授权，本 Skill 不执行。

个人持有出租物业只作为资产估值来源、租金现金流、贷款和压力情景 overlay。物业经营、折旧/税务定案和买卖建议路由相邻任务。
