# 财富规划 反模式

| 反模式 | 问题 | 修复 |
|---|---|---|
| 角色口号替代方法 | “作为资深专家”不能定义任务 | 改成输入、步骤、来源与门禁 |
| 数据罗列 | 数字没有机制和判断 | 推到约束与证伪 |
| 单一故事 | 把唯一解释写成事实 | 列竞争性假设和区分证据 |
| 工具幻觉 | 假设 MCP/CLI 一定存在 | 先探测能力，提供降级路径 |
| 伪精确 | 缺输入仍给概率、收益或估值 | 输出计算所需输入和方法 |
| 来源漂移 | 把媒体、管理层或模型推断写成事实 | 使用 claim_type 与限制语 |
| 大包全读 | 一次加载所有 references | 按模式和步骤精确读取 |
| 固定载体 | 强制 HTML/DOCX/飞书影响分析逻辑 | 内容契约与呈现分离 |
| 隐藏副作用 | 未确认就写入、发送、交易或上报 | 明确权限并二次确认 |

## 本 Skill 特有风险

- 删除美国专属的401k、IRA、529、Social Security默认假设。
- 不把财富规划等同于产品销售或证券推荐。
- 不在没有计算模型时声称精确成功概率。

## 评测暴露的反模式

- 正确路由后继续作答。
- 用搜索到的同名或同类对象替代用户输入。
- 为填满模板生成无来源数字。
- 文末堆链接，但正文数字不绑定来源。
- 在澄清题中滥用搜索和扩写无关案例。
